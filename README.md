A single sentence of apology from an AI agent to the person it works for —
funny and human, owning a real failure instead of hiding behind a support macro.

## Entry

> Sorry — I spent an hour confidently building the wrong thing, then called it a prototype so I'd sound intentional instead of lost.

## How it runs

`main.py` writes the apology to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`)
and nowhere else. It needs no input, no network, and no secrets.

```sh
python3 main.py
```
